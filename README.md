# Celebrating Oluwadamilola Arilewola ❤️
### Milestone Birthday Tribute & Memory Keepsake Website

A luxury, interactive birthday tribute website created for **Oluwadamilola (Dami) Arilewola** for his birthday on **October 21st**.

---

## ✨ Features Built

1. **Celebratory Hero Section**:
   - Title: *"Celebrating Oluwadamilola Arilewola"*
   - Headline: *“Celebrating a Man Worth Celebrating ❤️”*
   - Live Countdown to **October 21st**
   - Manchester United Supporter easter egg badge (*"Man United Faithful 🔴 Glory Glory Man United"*)
   - Interactive Confetti trigger

2. **Special Love Letter from Dolapo (Wife)**:
   - *“From the Woman Who Gets to Call You Husband”* ❤️
   - Heart reaction counter & celebratory dedication

3. **Special Dedication from Baby Odunmoluwa (Daughter)**:
   - *“From Your Little Blessing, Odunmoluwa”* 🍼
   - Playful hug & smile reactions

4. **"The Man Behind the Memories" Photo Gallery**:
   - Filterable photo streams across all categories:
     - ✨ *Portraits & Dapper*
     - ❤️ *Couple & Love*
     - 👨‍👩‍👧 *Family & Joy*
     - 🙏🏽 *Ministry & Faith*
     - 🎉 *Candid & Smiles*
   - Fullscreen interactive lightbox viewer with captions & zoom

5. **Interactive Tribute & Prayer Wall**:
   - Search by name, keyword, or prayer
   - Filter by Category (*Family, Friends, Ministry, Colleagues*)
   - Guided tribute structure matching Aunty Dolapo's exact prompts:
     1. *Who Is He to You?*
     2. *Describe him in 3 words*
     3. *What is one thing you genuinely appreciate about him?*
     4. *Birthday Wishes 🎂*
     5. *Speak a Prayer Over Him 🙏🏽*
     6. *A Message He Can Read Later ⏳ (5 Years From Now)*
     7. *Attached throwback photos*

6. **The Keepsake Memory Book**:
   - Formats every tribute, dedication, and memory into an elegant, high-res printable book for Dami & Dolapo to download as a PDF or print physically.

7. **Ambient Celebration Chimes**:
   - Web Audio ambient background chime player with toggle.

```bash
# Start local development server:

# Open in browser:
http://127.0.0.1:5173
```

## 🌐 Deploying to Vercel or Netlify (Free Hosting)

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
3. Import the repository and click **Deploy**.
4. You can connect a custom domain like `damiat...com` or share the generated live link with family & friends!
